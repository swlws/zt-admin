## 页面结构

```text

├── DrawerHeader
│   ├── Title
│   └── CloseIcon
├── OrderForm
│   ├── CustomerSection
│   ├── DeviceAndFaultSection
│   ├── ContactSection
│   ├── ServiceSection
│   └── PrioritySection
└── DrawerFooter
    ├── ContinueCreateCheckbox
    ├── CancelButton
    └── SubmitButton
```

## 优先级选项

优先级使用单选按钮，默认选中 `高`。

```text
高
中
低
```

## 底部操作区

底部操作区固定在抽屉底部，包含继续创建选项和提交/取消按钮。

| 元素 | 内容 | 说明 |
| --- | --- | --- |
| 复选框 | 继续新建下一条 | 提交后是否保持新建流程 |
| 取消按钮 | 取消 | 关闭抽屉或放弃本次新建 |
| 提交按钮 | 提交 | 提交新建工单表单 |

## 交互规则建议

| 交互 | 建议 |
| --- | --- |
| 关闭抽屉 | 若表单已填写，提示是否放弃更改 |
| 提交校验 | 校验所有必填项：客户名称、设备名称、故障类型、联系人、联系电话、服务地址、优先级 |
| 继续新建 | 勾选后提交成功保留抽屉，并重置除可复用客户信息外的字段 |
| 设备选择 | 可根据客户名称过滤设备列表 |
| 故障类型 | 可与设备型号联动，优先展示常见故障 |
| 预约时间 | 建议限制为当前时间之后 |
